# 予約メール媒体判定の修正（2026-10-31）

## 利用者への影響

HPB予約メールの備考・要望・メニューに「ミニモ」という文字が含まれても、件名がSALON BOARDまたはHOT PEPPER Beautyを示す場合はHPB予約として同期する。ミニモメール本文にHOT PEPPER Beautyという文字が含まれる場合も、ミニモの件名を優先する。

これにより、顧客が入力した他媒体名を理由に予約番号の解析が止まり、スタッフが手入力する状況を防ぐ。

## 変更範囲

- 媒体を一意に示す予約メール件名を、本文中の自由入力語より先に評価する。
- 件名だけで媒体を一意に決められないメールは、従来どおり本文の媒体表示と予約番号／IDから判定する。
- DB、権限、環境変数、実メール送信は変更しない。

## 検証範囲

- HPB件名と予約番号を持ち、本文の顧客要望に「ミニモ」を含む予約をHPBとして更新する。
- ミニモ件名と予約IDを持ち、本文のメニューに「HOT PEPPER Beauty」を含む予約をミニモとして更新する。
- 既存のHPB／ミニモ同期、遅延照合、重複防止の回帰テストを実行する。

実Gmail、実Supabase、実顧客データでの同期は未実施。
