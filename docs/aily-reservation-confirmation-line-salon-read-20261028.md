# 予約確定LINEの店舗外読取を防ぐ修正（2026-10-28）

## 利用者への効果

スタッフが確定済み予約のLINE通知を送るとき、最初の予約取得から認証済みスタッフの所属店舗に限定します。別店舗の予約IDが指定されても、店舗外の予約行を管理権限で先に読み取らず、顧客情報の取得、通知claim、LINE送信へ進みません。

## 修正内容

- 予約確定LINE APIの最初の予約取得へ、認証済みスタッフの `salon_id` 条件を追加する。
- 取得後の店舗一致確認を防御として維持する。
- 既存の確定状態確認、外部予約拒否、顧客・担当者の店舗照合、送信claim、再送キー、結果不明時の再送防止を維持する。
- 店舗条件が最初の予約取得に含まれることを回帰テストで固定する。

## 確認条件

- 最初の予約取得が予約IDと認証済み店舗IDの両方で絞られること。
- 同じ店舗の確定済み予約は従来どおり通知処理へ進むこと。
- 送信済み、送信中、再試行期限切れ、結果不明の既存ガードが維持されること。

## 反映範囲と未検証

Aily実DB、実顧客LINE、実機、Preview、本番は未検証・未変更です。DB migration、RLS、環境変数、実送信の変更はありません。予約確定LINE用DBオブジェクトの実DB適用状況はこのコード検証だけでは確定しません。
