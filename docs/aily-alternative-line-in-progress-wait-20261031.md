# 別日時LINE送信中の再操作防止

## 利用者が新しくできること

別のタブや端末で別日時入力LINEの送信が進行中だった場合、予約編集画面に送信中の案内を表示し、5分間は同じ送信ボタンを再表示しない。5分後は画面を開いたままでも待機表示が解除され、必要な場合だけ安全な再試行へ進める。

## 対象操作

1. 予約編集画面で「別日時をLINEで依頼」を選ぶ。
2. 同じ予約の送信がすでに進行中なら、LINE APIを追加で呼ばず待機案内を表示する。
3. DB側の送信中ロックと同じ5分が経過すると、操作ボタンを再表示する。

## 検証範囲

- 送信中応答に5分の待機情報が含まれること。
- 送信中はLINE APIと送信完了更新を呼ばないこと。
- 待機状態が同じ予約内容にだけ保存され、5分後に失効すること。
- 画面を開いたままでも待機状態が解除されること。

実DB、実LINE送信、スタッフ認証済み実データの通し確認は未実施。
