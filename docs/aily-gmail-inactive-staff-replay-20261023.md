# Gmail予約再処理の退職スタッフ依存解消（2026-10-23）

## 利用者に変わること

HPB／minimoから取り込んだ予約の担当者が後日退職・無効化されても、既に同期済みの同一メールをGmail同期が再取得しただけで同期全体が失敗しなくなる。

既存予約のキャンセルメールも、予約を特定できている場合は過去の担当者が有効スタッフに残っていることを要求せず、キャンセルを反映できる。

## 安全性を維持する範囲

- 新規予約は、従来どおりメール記載の担当者を同じサロンの有効スタッフから一意に確認して保存する。
- 日時・メニュー等が変わった予約変更メールも、従来どおり担当者を再確認する。
- 完全に同じ同期済みメールだけ、予約への再書込みと不要な担当者検索を行わない。
- 予約番号に一致する既存予約がないキャンセルは、保存に必要な情報と担当者を従来どおり確認する。

## 受入条件

1. 退職・無効化済み担当者を含む同一メールの再処理が、書込みなしで成功する。
2. 既存予約のキャンセルは、過去担当者の有効状態に依存せず反映できる。
3. 変更メールは担当者確認を省略せず、確認できない場合は書込み前に停止する。
4. 新規予約は有効な担当者IDを保存する。
