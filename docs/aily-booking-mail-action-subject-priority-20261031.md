# 予約件名を優先した予約・キャンセル判定

## 対象

- HPB / SALON BOARD とミニモの予約メール同期
- 通常予約メールのメニュー・要望欄にキャンセル関連文言が含まれるケース

## 修正した問題

通常予約の件名が明確でも、本文の自由記入欄に「ご予約のキャンセル」や「キャンセル理由」があると、現在の予約をキャンセル通知として処理する可能性がありました。スタッフが手入力で戻すまで新しい予約が一覧から消えるため、予約同期と重複確認に影響します。

## 変更内容

- 件名に「キャンセル」または `cancel` がある場合は、従来どおりキャンセルを優先します。
- HPBの「ご予約内容のお知らせ」とミニモの「新しい予約を受け付けました」は通常予約として優先します。
- 件名で判断できない手動貼り付け・転送メールは、従来どおり本文の定型句で判定します。

## 検証範囲

- HPB通常予約の要望欄に「前回のご予約のキャンセル」があるケース
- ミニモ通常予約のメニューに「キャンセル理由」があるケース
- 件名だけがキャンセルの既存HPB / ミニモ通知
- 件名なし・本文だけの既存キャンセル通知
