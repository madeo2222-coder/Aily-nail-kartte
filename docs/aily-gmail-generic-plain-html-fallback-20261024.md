# Gmail予約同期: 一般案内テキストからHTML予約本文への切替

## 利用者ができること

HPB／minimoのメールで、件名とテキスト版が「詳しい内容はHTML版をご確認ください」のような一般案内だけでも、HTML版に予約番号・氏名・来店日時があれば予約同期へ進めます。

従来は、件名とテキスト版にサービス名や予約番号がないと対象外扱いになり、Gmail検索がメールを見つけてもHTML版を確認せず同期を飛ばす経路がありました。

## 変更内容

- テキスト版を完全な予約メールとして解析できた場合は、従来どおりHTML版を取得しない。
- テキスト版が対象外または予約項目不足の場合だけHTML版を確認する。
- HTML版が完全な予約メールなら、既存の予約同期処理へ渡す。
- HTML版も対象外なら、従来どおり対象外としてスキップする。

DB schema、migration、RLS、環境変数、Gmail OAuth、実送信は変更しない。

## 検証

- 一般的な件名と案内テキスト、予約項目を含むHTML版のfixtureを追加する。
- HTML版が同期対象として選ばれ、予約同期処理へ1回だけ渡ることを確認する。
- 既存のplain優先、HTMLフォールバック、添付除外、失敗隔離を含む回帰を実行する。

## 未検証範囲

Aily実Gmail、実DBへの保存・再表示、実スタッフ認証での通し確認は未実施。確認版へ反映するまでは保存済みコードであり、現場導入済みとは扱わない。
