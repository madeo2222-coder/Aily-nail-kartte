# 顧客予約の申請中ステータス正規化

## 利用者ができること

- 旧データの予約状態が全角英字や空白を含んでいても、申請中の予約を顧客予約詳細から変更・取り消しできる。
- 画面の操作可否と、保存時のAPI判定が同じ予約状態を申請中として扱う。

## 変更範囲

- 顧客予約詳細APIで、予約状態をNFKC正規化し、空白と英字の大小差を除いてから申請中・確定を判定する。
- 既存の顧客本人確認、予約所有者確認、外部予約の編集拒否、空き枠確認、原子的な更新・取消RPC、LINE通知結果の扱いは維持する。
- DB、migration、環境変数、認証方式、実データ、外部送信、本番環境は変更していない。
