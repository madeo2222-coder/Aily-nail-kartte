# 外部予約のスタッフメモ分離（2026-10-22）

## 現場で変わること

- HPB／ミニモから同期した予約の編集画面では、「メモ」にスタッフが追記した内容だけを表示する。
- 予約番号、同期照合情報、取込メール原文は画面で誤編集させず、日時・担当・メニュー等を更新しても裏側で保持する。
- スタッフメモの追加・変更・削除は `【同期前の手入力メモ】` セクションだけへ反映し、次回メール同期でも引き継げる。
- 通常予約のメモ、Gallery参照情報、外部予定の判定は従来どおり維持する。

## 実装範囲

- `lib/reservation-sync-memo.ts`
  - HPB／ミニモのメール本文境界を検出する。
  - スタッフ所有のメモ部分だけを編集値として切り出す。
  - 保存時は同期管理部分を不透明なテンプレートとして保持し、スタッフメモ部分だけを差し替える。
- `app/reservations/edit/[id]/page.tsx`
  - 同期予約だけスタッフメモと同期管理部分を状態分離する。
  - 保存・予約確定の双方で分離した内容を安全に再構成する。
  - 同期情報とメール本文が保持される旨をメモ欄に表示する。
- `app/api/reservations/[id]/staff-edit/route.ts`
  - 画面読取時の予約状態・メモ・開始／終了時刻を更新条件に加える。
  - 画面表示後にGmail同期や別操作がメモまたは予約時刻を先に更新した場合は上書きせず、409と再読込案内を返す。
  - API読取後から書込み直前に競合した場合も、比較更新0件を成功扱いしない。

DB migration、環境変数、外部送信、実データ変更はない。
