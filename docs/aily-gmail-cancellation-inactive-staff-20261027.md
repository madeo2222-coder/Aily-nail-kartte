# Gmailキャンセル同期：無効化済み担当者での保存継続

## 利用者ができること

元のHPB/minimo予約メールを取り逃がした場合でも、キャンセルメールに記載された担当者が退職・無効化・改名済みなら、キャンセルを失わず記録できる。

- 顧客と来店時刻で手入力予約を一意に特定できる場合、その予約をキャンセルへ更新する。
- 手入力予約がない場合、外部予約番号のキャンセル記録を保存し、後から古い予約メールが届いても予約を再有効化しない。
- 担当者を一意に特定できなければ担当者欄は空のままにする。
- 顧客・日時に複数候補がある場合は、従来どおり誤キャンセルを避けて停止する。

## 変更範囲

- 既存予約がないキャンセルに限り、担当スタッフの解決を任意にした。
- 通常の新規・変更予約では有効な担当スタッフの一意特定を引き続き必須とした。
- DB schema、migration、認証、環境変数、外部送信は変更していない。

## 検証

- 無効化済み担当者を含むキャンセルが、担当者なしのキャンセル記録として保存されること。
- 同じ顧客・時刻の手入力予約が1件なら、その予約がキャンセルへ更新されること。
- 通常の新規・変更予約は、無効化済み担当者のまま保存されないこと。
