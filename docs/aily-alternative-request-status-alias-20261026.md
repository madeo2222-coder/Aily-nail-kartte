# 別日時提案の申請中ステータス互換

## 利用者ができること

過去データに全角英字や空白を含む「申請中」ステータスが残っていても、スタッフは予約詳細から別日時提案のLINE通知を開始できます。通常の `requested`、`予約申請中`、`予約受付`、`予約` の挙動は変わりません。

## 変更範囲

- 別日時提案APIの申請中判定だけを、既存の予約画面と同じくNFKC正規化・空白除去・小文字化して判定
- 更新競合を防ぐ予約スナップショットは保存値との完全一致を維持
- LINE再送キー、送信状態、スタッフ認証、所属制限、外部予約拒否は変更なし
- DB、migration、環境変数、実顧客データ、実LINE送信は変更なし

## 検証

- ` ＲＥＱＵＥＳＴＥＤ ` と ` 予 約 申 請 中 ` の両方で、完全一致するスナップショットから送信処理へ進むこと
- 既存の認証、所属、外部予約、古いスナップショット、送信失敗・再試行・送信済み収束の回帰テスト
- 型検査、lint、ローカルfixture build
