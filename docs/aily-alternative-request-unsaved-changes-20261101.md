# 別日時LINE依頼前の未保存変更ガード（2026-11-01）

## 利用者ができること

スタッフが予約編集画面で日時・顧客・担当・メニュー・状態・メモ・サロンを変更したまま「別日時をLINEで依頼」を押した場合、古い保存済み予約を基にLINEを送る前に操作を止める。

画面には「変更を保存」または最新情報の再読み込みを促す案内を表示する。保存済みの予約内容と画面内容が一致する場合だけ、従来の確認ダイアログと別日時LINE依頼へ進む。

## 受入条件

- 未保存変更がある場合、確認ダイアログ、再送ロック確認、LINE依頼APIの呼び出しへ進まない。
- 未保存変更がない場合、既存の再送防止、予約スナップショット照合、失敗時の再試行制御を維持する。
- 日時はDBと画面の表記差ではなく同一時刻として比較し、空文字とNULLの差だけで誤って未保存扱いにしない。

## 検証範囲

関連テスト、全回帰テスト、型検査、変更ファイルのlint、fixture環境でのNext.js本番ビルドを行う。

Aily本番DB、実LINE送信、環境変数、認証設定、本番公開は変更しない。実環境でのスタッフ操作と実LINE到達は未検証とする。
