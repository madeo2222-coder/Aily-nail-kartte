# 予約メールの構造化IDによる送信元判定

## 対象

- HPB / SALON BOARD とミニモの予約メール同期
- 件名に送信元名が含まれない転送・手動取り込みメール

## 修正した問題

件名が「ご予約内容のお知らせ」のような共通文言だけの場合、本文の自由記載欄に別サービス名があると、その語を送信元と誤認する可能性がありました。たとえばHPB予約の要望欄に「ミニモで見たデザイン」と書かれていると、HPBの予約番号があるにもかかわらずミニモ形式として解析し、予約同期が止まる状態です。

## 変更内容

- 件名で送信元を一意に判断できない場合、本文の構造化ID行を優先します。
- `予約番号` とHPB形式の番号がある場合はHPBとして解析します。
- `予約ID` がある場合はミニモとして解析します。
- 両方があるなど送信元を一意に判断できない場合は、従来の保守的な判定へ戻します。

## 検証範囲

- 共通件名 + HPB予約番号 + ミニモへの自由記載
- 共通件名 + ミニモ予約ID + HPBを含むメニュー名
- 既存の送信元件名、キャンセル、遅延同期、重複防止の回帰テスト
