# HPB／minimoメール同期：媒体判定の優先順位（2026-10-31）

## 利用者ができること

HPBの予約メール内に連携先などの補助的な「予約ID」が含まれていても、SALON BOARD、HOT PEPPER Beauty、または「予約番号」が確認できる場合はHPB予約として同期できる。

## 修正範囲

- ミニモ／minimoの明示表記があるメールは従来どおりminimoとして解析する。
- HPBの明示表記または「予約番号」がある場合、単独の「予約ID」だけでminimoへ切り替えない。
- 媒体名がなく「予約ID」だけがある既存のminimo形式は従来どおり受け付ける。
- DB、migration、認証、環境変数、外部送信は変更しない。

## 受入条件

1. HPBの明示情報と補助的な「予約ID」が同居するメールをHPB予約番号で同期する。
2. 既存のHPB／minimo予約受付、変更、キャンセル、遅延同期の回帰テストが成功する。
3. 型検査、lint、ローカル本番buildが成功する。
