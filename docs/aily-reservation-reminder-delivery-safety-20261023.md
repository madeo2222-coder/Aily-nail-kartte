# 予約前日リマインドLINEの送信安全化（2026-10-23）

## 段階納品の対象

スタッフが予約前日のLINEリマインドを実行するとき、所属店舗の確定予約だけを対象にし、準備中に予約内容が変わった場合や送信履歴を確認できない場合は送信しない。

## 今回の変更

- 予約・顧客・担当者の読取を認証スタッフの所属サロンへ限定
- `confirmed` と既存日本語状態 `予約確定` を同じ確定予約として扱う
- 対象日を厳密な `YYYY-MM-DD` の実在日だけに制限
- 送信直前に予約を再読取し、顧客・担当・メニュー・日時・状態の変更を検知したら停止
- 送信履歴の読取失敗を未送信とみなさず、安全側に停止
- 予約ID・対象日から安定したLINE再送キーを生成し、応答喪失後の再実行で同じキーを利用
- LINEが同じ再送キーを受付済みと返した場合は重複送信せず、送信記録を収束
- LINE受付後にDBの送信記録保存が失敗した場合は成功扱いにせず、受付済み・記録失敗として件数表示
