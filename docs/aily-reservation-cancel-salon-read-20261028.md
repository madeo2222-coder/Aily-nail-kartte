# 予約取消の店舗外読取を防ぐ修正（2026-10-28）

## 利用者への効果

スタッフが予約をキャンセルするとき、予約の最初の取得から認証済みスタッフの所属店舗に限定します。別店舗の予約IDが指定されても、店舗外の予約行を管理権限で読み取らず、キャンセルやLINE通知へ進みません。

## 修正内容

- 予約取消APIの最初の予約取得へ、認証済みスタッフの `salon_id` 条件を追加する。
- 既存の予約内容スナップショット照合、外部予約拒否、条件付き更新、重複LINE送信防止を維持する。
- 店舗条件が予約取得より後に評価される経路を残さない回帰テストを追加する。

## 確認条件

- 最初の予約取得が予約IDと認証済み店舗IDの両方で絞られること。
- 同じ店舗の通常予約は従来どおりキャンセルできること。
- HPB・ミニモ予約、古い画面、来店・完了後の予約、同時更新、LINE結果不明時の既存ガードが維持されること。

## 反映範囲と未検証

Aily実DB、実顧客LINE、実機、Preview、本番は未検証・未変更です。DB migration、RLS、環境変数、実送信の変更はありません。統合Previewへの反映は、6時間間隔と最新の並行作業を照合した次の単一バッチで行います。
