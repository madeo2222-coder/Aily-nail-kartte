# 海外向けネイルチップ相談の再読込後重複防止（2026-11-03）

## 利用者が新しくできること

- 海外向けネイルチップ相談の送信中に通信が切れたり応答を受け取れなかったりしても、同じタブを再読込して結果を確認できる。
- サーバーに保存済みなら再送せず送信完了として表示する。
- 未保存と確認できた場合だけ、同じ操作ID・相談内容・画像URLで安全に再試行できる。
- 保存結果を確認できない間は送信をロックし、「結果をもう一度確認」から再照合できる。

## 実装範囲

- 送信直前にランダムな操作IDと相談内容をタブ内の一時ストレージへ保存する。
- 公開GET APIは操作IDに対応する保存有無だけを返し、相談内容や顧客情報は返さない。
- POST APIは操作IDを `inbound_nail_tip_requests.id` として使用し、同じID・同じ内容の再受信を成功へ収束させる。
- 同じ操作IDで内容が異なる場合は409で拒否する。
- メールと管理者LINE通知へ操作ID由来の冪等キーを付ける。
- タブ内の保存内容は成功時または確定エラー時に削除する。

## 確認した業務

- 初回送信前に操作IDと相談内容が保存される。
- 応答喪失後も同じ画面内で二重送信を止める。
- 再読込後に保存済みを確認した場合、POSTを再実行せず完了表示へ移る。
- 再読込後に未保存を確認した場合、画像を再アップロードせず同一操作IDで再試行する。
- APIの同一再送、内容不一致、競合挿入、保存済み・未保存・判定不能の照合を確認する。
- 無効な操作IDは管理接続を開く前に拒否する。
