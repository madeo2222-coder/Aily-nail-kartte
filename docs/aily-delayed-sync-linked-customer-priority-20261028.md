# HPB／minimo遅延同期：顧客紐付け済み候補の優先（2026-10-28）

## 利用者が新しくできること

スタッフが同じ5分枠へ複数の外部予約を先に手入力していても、後から届いたHPB／minimoメールの顧客IDと外部予約種別が一致する予約が1件なら、その予約へ安全に同期できます。顧客未紐付けの同種予約が同じ枠にあっても、照合可能な予約まで曖昧扱いで停止しません。

## 保護条件

- 顧客IDと外部予約種別が両方一致する候補が複数なら、従来どおり同期を停止します。
- 顧客IDが一致する候補がない場合や、別顧客との競合がある場合の停止条件は維持します。
- 取消済み予約、別の外部予約種別、既に外部予約番号が付いた予約は候補にしません。
- DB、migration、認証、環境変数、実データ、実LINE／メール送信は変更していません。
