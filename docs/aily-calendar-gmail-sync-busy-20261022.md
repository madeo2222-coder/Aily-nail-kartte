# 予約カレンダー Gmail 同期の連打防止（2026-10-22）

## 利用者への変更

予約カレンダーの「予約今すぐ同期」を素早く複数回押しても、最初の Gmail 同期が終わるまで追加の同期要求を送らないようにした。

## 原因と修正

従来は React の `syncingHpb` 状態でボタンを無効化していたが、クリック直後から再描画までの短い間は同じハンドラーをもう一度実行できた。そのため、状態更新とは別の同期的な `useRef` ロックを追加し、API 呼び出しより前に取得、成功・一部失敗・例外のいずれでも `finally` で解放する。

## 検証範囲

- 再描画前に同期ボタンのハンドラーを2回連続実行しても、`POST /api/hpb-gmail-sync` が1回だけ送られること
- 既存の同期結果表示、カレンダー再取得、失敗時のエラー表示は変更していない
- 全回帰745件中743件成功、失敗0件、任意PGlite 2件skip
- 独立TypeScript検査、全ESLint、diff checkに成功
- 実資格情報を継承しないfixture設定のNext.js production webpack buildに成功（93/93ページ、最終trace、exit 0）
