# 別日時LINE依頼の競合時再読込（2026-11-01）

## 利用者に変わること

スタッフが予約編集画面を開いている間に別の端末や同期処理が予約を更新した場合、別日時LINEは送信前に停止し、同じ画面へ最新の予約内容を自動反映する。スタッフは表示された最新内容を確認してから操作をやり直せる。

空き枠競合、LINE送信失敗、通知結果不明など、予約内容の更新競合ではないエラーでは自動再読込を行わず、既存のエラー表示と再送防止を維持する。

## 実装範囲

- 別日時依頼APIの予約スナップショット競合に `stale_reservation` を付与
- 予約読取後から送信権取得までに状態が変わった競合にも同じコードを付与
- スタッフ予約編集画面はこのコードだけを対象に予約詳細を再取得
- 最新情報の取得に成功した場合は、画面反映済みであることを明示

DB、migration、認証方式、環境変数、LINE送信処理の仕様は変更していない。
