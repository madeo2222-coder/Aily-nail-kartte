# 転送予約メールの自由記入欄による誤キャンセル防止

## 対象

- HPB / SALON BOARD とミニモの予約メール同期
- 転送などで件名が一般化した通常予約メール

## 修正した問題

件名が「予約のお知らせ」などに変わった通常予約メールでは、顧客の要望欄やメニュー名に「ご予約のキャンセル」「キャンセル理由」が含まれると、現在の予約をキャンセル通知として処理する可能性がありました。

## 変更内容

- 「ご要望」「要望」「メニュー」「備考」「コメント」「お客様からのメッセージ」の値は、キャンセル通知の本文判定から除外します。
- 件名にキャンセルが明記されている通知は従来どおりキャンセルを優先します。
- 自由記入欄ではない本文の定型キャンセル文は従来どおり有効です。

## 検証範囲

- 一般化した件名のHPB予約で、要望欄に過去予約のキャンセル相談があるケース
- 一般化した件名のミニモ予約で、メニュー名にキャンセル理由があるケース
- 件名・本文による既存キャンセル判定の回帰
