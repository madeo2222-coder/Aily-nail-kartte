# 外部予定登録の待機上限（2026-11-04）

## 対象業務

スタッフがHPB・minimoなどの外部予約を手入力し、予約カレンダーの予定ブロックとして登録する操作。

## 変更

- 登録APIのブラウザ待機を15秒で終了する。
- 待機超過や応答喪失では結果不明として登録操作をロックし、予約カレンダーでの確認へ案内する。
- 既存の操作ID、別タブ送信ロック、再読込後の保存済み・未保存照合を維持する。

## 受入条件

1. 正常応答では登録完了を表示し、同じ入力の操作IDを終了する。
2. 明示失敗ではエラーを表示し、安全に再登録できる。
3. 応答喪失または15秒の待機超過では同じ操作を再送せず、保存状態の照合へ移る。
4. 再読込後に保存済みなら登録済みと表示し、未保存なら同じ操作IDで再登録できる。
5. 別タブが登録中なら2件目を送らない。

## 未検証範囲

- Aily本番Supabaseへの実書込み
- 認証済みスタッフ端末での登録・再表示
- HPB・minimoの実予約との照合

DB、認証、env/secret、実LINE・メール送信、main、本番は変更しない。
