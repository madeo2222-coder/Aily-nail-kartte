# スタッフ予約登録の再読込後の保存結果確認（2026-11-03）

## 利用者が新しくできること

スタッフが予約を登録した直後に通信が切れ、登録結果を確認できないままページを開き直した場合、保存済みの予約を読取で確認する。保存済みなら予約カレンダーへ移動し、同じ予約を再登録しない。

## 修正範囲

- 結果不明時に端末へ残した予約登録操作IDを、ページ初期表示時の認証済みAPIへ渡す。
- APIは個別スタッフ認証では所属サロンに限定して予約IDの存在を確認する。
- 保存済みを確認した場合は端末の保留操作を破棄し、予約カレンダーへ移動する。
- 読取結果が不明な場合は再送を止め、予約カレンダーで最新状態を確認する案内を維持する。
- 未保存を確認した場合は入力内容を確認して必要な場合だけ登録でき、既存の同一操作IDを再利用して重複保存を防ぐ。

DB migration、権限、環境変数、実データ、LINE・メール送信は変更していない。
