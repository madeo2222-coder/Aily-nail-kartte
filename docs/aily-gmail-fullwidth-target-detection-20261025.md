# Gmail予約メールの全角対象判定

## 対象

全角英数字を含むHPB／minimo予約メールが、本文解析へ到達する前のGmail検索または対象判定で除外される経路を修正する。

## 変更

- Gmail検索語へ全角の `ＭＩＮＩＭＯ` と `予約ＩＤ` を追加する。
- 件名と本文の対象判定をNFKC正規化・小文字化し、全角／半角および英字大小文字の表記差を同一として扱う。
- 予約番号、SALON BOARD、HOT PEPPER Beauty、ミニモ、予約IDという既存の対象条件は維持する。
- 対象判定後の予約番号、日時、電話番号、重複、サロン所属の検証は既存パーサーと保存処理で引き続き行う。

## 検証範囲

一般的な件名で、本文だけに全角 `ＭＩＮＩＭＯ` と `予約ＩＤ` があるメールが解析・同期処理へ渡ることを自動テストで確認する。

実Gmail検索、Aily実DBへの保存、予約画面の再表示は未検証。本変更にDB migration、権限、環境変数、外部送信の変更はない。
