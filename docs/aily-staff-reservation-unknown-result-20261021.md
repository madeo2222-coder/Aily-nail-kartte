# スタッフ予約操作：応答不明時の重複操作防止

## 今回の修正

スタッフの予約編集画面で「予約確定」または「別日時をLINEで依頼」を実行した後、通信断やJSON応答の解析失敗が起きると、サーバー側では処理済みでも画面は単純な失敗として扱っていた。この状態で同じ操作を繰り返すと、確定処理や通知を重複して試す原因になる。

結果を確認できない場合は「失敗」と断定せず、結果不明の警告と「最新情報を再読み込み」を表示する。最新状態を取得できるまで、予約確定、確定LINE再試行、別日時LINE依頼、予約更新、予約削除の全操作を無効化する。再読み込みが成功した場合だけ結果不明状態を解除する。

既存のサーバー側の再送キー、送信記録、重複予約確認、スタッフ認証・所属制限は変更していない。DB、migration、環境変数、予約データ、実LINE送信、本番公開も変更していない。

## 利用者が確認できること

- 予約確定または別日時LINE依頼の応答が途切れた場合、同じ操作を繰り返さない案内が表示される。
- 「最新情報を再読み込み」で予約状態と通知状態を確認できる。
- 最新情報の取得に成功するまで、競合する予約操作を再実行できない。
- 正常応答および明示的なAPIエラーの従来表示は維持される。
