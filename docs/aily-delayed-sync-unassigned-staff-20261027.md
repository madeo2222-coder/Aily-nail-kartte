# HPB／minimo遅延同期：担当未割当の手入力予約を再利用

## 利用者ができること

HPB／minimoのメール到着前にスタッフが予約を手入力し、その時点では担当者を未割当としていても、後から届いたメールに担当者が記載されていれば、同じ手入力予約へ同期できます。メール同期時に担当者が補完され、同時刻の予約が別行として増える経路を減らします。

操作方法は従来どおりです。予約カレンダーの「予約今すぐ同期」を実行します。

## 照合条件

- 同じサロン、開始時刻の前後5分以内で照合する。
- HPB／minimoの印がある手入力予約、または同じ顧客に紐づく手入力予約を候補とする。
- 手入力予約の担当者が未割当なら、メールで特定できた有効スタッフを設定する。
- 手入力予約に別の担当者が設定済みなら候補から除外する。
- 候補が複数ある場合、誤更新を避けるため同期を停止する。
- キャンセル済み予約、別顧客の予約、別媒体の予約、外部予約番号が保存済みの予約は従来どおり再利用しない。

## 受入条件

1. 同じ顧客・同時刻で担当未割当の手入力予約が1件ある。
2. 担当者を含むHPB／minimo予約メールを同期する。
3. 新しい予約を追加せず、既存の手入力予約IDを更新する。
4. 更新後の予約にメールの担当者が保存され、手入力メモが維持される。
5. 同期中に担当者が変更された場合は更新0件として止まり、変更済みの担当者を上書きしない。

## 検証範囲

- 候補選定の単体テストで、未割当は採用し、別担当の予約は除外することを確認する。
- 共通メール同期の回帰テストで、既存予約IDへの更新、担当者補完、担当未割当を条件にした競合検知、新規INSERTなしを確認する。
- DB migration、環境変数、認証、Gmail設定は変更しない。
