# 外部予定登録の再読込後照合（2026-11-03）

## 利用者・目的

スタッフがHPB・ミニモ・電話予約を外部予定として登録した直後に通信結果を失っても、ページ再読込後に保存結果を自動確認し、重複ブロックを作らず業務を再開できるようにする。

## 今回の納品範囲

- ブラウザに残った登録操作IDを、スタッフ認証済みの初期読取APIへ渡す。
- 個別スタッフ認証では所属サロンに限定して、同じIDの外部予定が保存済みか確認する。
- 保存済みなら端末の保留操作を消し、予約カレンダーで確認できる旨を表示する。
- 未保存を確認できた場合は、同じ内容の再登録で既存の操作IDを再利用する。
- 読取に失敗した場合は登録を止め、結果の再確認または予約カレンダー確認へ案内する。
- 既存の署名済み共有ログイン、スタッフ所属、日時、重複予約、同時登録の保護を維持する。

## 受入条件

1. 応答喪失後の再読込で保存済みなら、再POSTせず保存済み表示へ変わる。
2. 未保存なら、同じ内容の再登録が同じ操作IDを使う。
3. 読取結果が不明な間は登録ボタンを無効にし、重複登録しない。
4. 個別スタッフの照合は所属サロンに限定される。
5. 不正な操作IDはservice roleのDB読取前に拒否される。
