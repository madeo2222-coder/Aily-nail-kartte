# Gmail予約同期：キャンセル時の任意項目異常を分離（2026-10-25）

## 利用者への影響

- HPB／minimoのキャンセルメールで電話番号が非公開、または施術時間が未定でも、外部予約番号に一致する既存予約をキャンセルできる。
- 新規予約メールの電話番号・施術時間は従来どおり厳格に検証し、不正な値はDBアクセス前に停止する。
- 外部予約番号に一致する予約がなく、正常な来店日時と終了日時を作れないキャンセルは新規保存しない。

## 変更範囲

- `lib/hpb-mail-sync.ts`
  - キャンセル時だけ、予約特定に不要な電話番号・施術時間の異常を許容
  - 不正な施術時間では終了日時を生成せず、未一致キャンセルの保存条件を満たさないよう維持
- `tests/hpb-mail-sync-customer-guard.test.mjs`
  - HPB／minimo双方で、既存予約のキャンセル成功を確認
  - 同じ入力で一致予約がない場合は書込み前に停止することを確認

DB schema、migration、RLS、環境変数、実データ、外部送信は変更していない。
