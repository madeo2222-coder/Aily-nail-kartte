# 予約更新・削除の競合時に最新内容を自動反映（2026-11-01）

## 利用者ができること

スタッフが予約編集画面で保存または削除を実行する直前に、別端末や予約同期で同じ予約が更新されていた場合、画面へ最新の予約内容を自動で反映します。古い顧客・担当・メニュー・日時・状態・メモを残したまま上書きや削除を再試行しません。

## 実装範囲

- スタッフ予約更新・削除APIは、読取後または書込み直前の競合を `stale_reservation` として返す
- 予約編集画面はこの競合だけを受け取ると予約詳細を再取得し、最新内容を表示する
- 更新時は最新内容を確認してから再保存、削除時は最新内容を確認してから再度削除確認する
- 日時重複、入力不備、所属外、外部予約など別のエラーでは入力内容を消さず、従来どおりエラーを表示する
- DB migration、権限、認証、通知処理は変更しない

## 現場受入条件

通常のスタッフ認証で予約編集画面を2端末で開き、片方で予約を変更した後、古い画面から保存または削除を実行する。最新内容が自動表示され、古い内容で更新・削除されないことを確認する。実DBを使うこの確認は、次回の許可済み単一Previewバッチへ統合した後に行う。
