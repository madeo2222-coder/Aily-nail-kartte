# 顧客アプリの次回予約ステータス正規化

## 利用者ができること

- 顧客ホームとマイページで、全角英字や空白を含む旧「完了」予約を次回・今後の予約として誤表示しない。
- 旧表記の確定予約も、マイページで「予約確定」と表示する。

## 変更範囲

- 顧客ホームの次回予約抽出に共通の完了判定を追加した。
- マイページの今後の予約から完了状態を除外し、予約状態名を共通の正規化処理へ統一した。
- 完了予約は直近の予約履歴としては維持し、次回予約の件数とカードだけから除外する。
- DB、migration、環境変数、認証方式、外部送信、本番環境は変更していない。
