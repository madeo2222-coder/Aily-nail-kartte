# Gmail予約メールの文字コード対応（2026-10-24）

## 利用者への効果

HPB／minimoの予約メール本文がUTF-8以外の日本語文字コードで届いた場合も、MIMEの`charset`指定に従って読み取れるようにした。ISO-2022-JP形式の予約メールが文字化けして解析保留になる経路を解消する。

## 変更範囲

- Gmail本文のBase64 URL復号後に、`Content-Type`の`charset`を使って文字列化する。
- `charset`がない既存メールは従来どおりUTF-8として扱う。
- 未対応または壊れた文字コードは代替文字で解析を続けず、そのメールを失敗として安全に保留する。
- DB、migration、RLS、環境変数、Gmail OAuth、LINE／メール送信設定は変更しない。

## 受入条件

1. ISO-2022-JPの日本語予約本文が、予約番号・氏名・来店日時を保ったUTF-8文字列として同期処理へ渡る。
2. UTF-8の既存メールとHTML／添付本文の処理を壊さない。
3. 未対応charsetではDB書込みを開始せず、再確認可能な失敗として返す。

- Aily本番DBへの書込み
