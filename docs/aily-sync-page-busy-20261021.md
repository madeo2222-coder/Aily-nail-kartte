# 同期センター：Gmailと手動同期の同時開始を防ぐ

## 原因と修正

`/hpb-mail-sync-test` の2つの同期ボタンは別々のbusy状態だけを参照していた。Gmail同期中に手動同期を開始でき、同じ画面から予約書込みを並行実行し、共有の結果表示も後着応答で上書きし得た。実ページのイベント処理を模擬fetchで実行し、同一レンダーの連続操作で3リクエスト開始を再現した。実店舗での重複事故を確認したものではない。

ページ単位の共通refで再レンダー前の連打も拒否し、既存2状態から導出したbusyで両ボタンを無効表示する。成功・API失敗・通信失敗・JSON解析失敗・部分失敗のいずれもfinallyで解除。空本文と確認ダイアログの取消ではロックを取得しない。既存の進行中ラベル、部分失敗表示、明示的な再試行を維持。API/認証/DB/送信処理は変更しない。
