# 予約メール再送時のサロン所属確認（2026-10-24）

## 利用者への変更

HPB／minimo予約メールの再送時に、予約番号が一致しても保存済み予約のサロンが現在の店舗と一致しない場合は、処理済み・キャンセル済みとして成功を返さず同期を停止する。

従来も更新SQLにはサロン条件があり、別サロンの予約を書き換えない保護はあった。一方、同じメール本文が保存済み、またはキャンセル済みの場合は更新前に成功を返すため、サロン未設定や別サロンの予約を現在店舗で処理済みと報告し得た。今回、成功判定より先に所属を検証する。

## 検証内容

- 別サロンにあるキャンセル済み決定IDを、現在店舗のキャンセル成功として扱わない
- サロン未設定の既存予約を、同じ予約メールの処理済みとして扱わない
- どちらもDB書込み前に停止する
- 同一サロンの予約更新、キャンセル再送、先着キャンセル、同時登録の既存動作を回帰確認する

## 変更しない範囲

- Supabaseのschema、migration、RLS、環境変数
- 予約・顧客データの自動修正や移動
- 実Gmail、実LINE、実顧客への送信

Preview反映後も、実DB上のサロン未設定・重複状態そのものは未確認である。今回の修正は、不整合を推測で補正せず対象メールだけを安全に停止する。
