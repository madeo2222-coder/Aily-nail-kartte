# Google口コミ依頼LINEの送信安全化（2026-10-23）

## 段階納品の対象

スタッフが来店済み顧客へGoogle口コミ依頼を送るとき、所属サロンの来店・顧客・口コミURLだけを利用し、応答喪失や履歴確認失敗で誤送信・重複送信しない。

## 今回の変更

- スタッフ認証に所属サロンを必須化し、サロン・来店・顧客の読取を同じサロンへ限定
- 対象日を厳密な `YYYY-MM-DD` の実在日だけに制限
- 送信直前に来店を再読取し、顧客・日付・所属サロンの変更を検知したら停止
- 送信履歴の読取失敗を未送信とみなさず、安全側に停止
- 来店ID・対象日から安定したLINE再送キーを生成し、応答喪失後の再実行でも同じキーを利用
- LINEが同じ再送キーを受付済みと返した場合は重複送信せず、送信記録を収束
- LINE受付後にDBの送信記録保存が失敗した場合は成功扱いにせず、受付済み・記録失敗として件数表示

## 受入条件

- 所属サロンの対象日来店だけが候補になる
- 別サロンの顧客や口コミURLを使用しない
- 送信準備中に来店情報が変わった場合は送信しない
- LINE応答喪失後の再実行で同じ再送キーを使用する
- 送信履歴確認失敗、送信失敗、送信記録保存失敗を成功件数へ混同しない
