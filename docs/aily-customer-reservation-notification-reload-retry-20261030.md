# 顧客予約通知の再読み込み後リトライ

## 利用者ができること

予約保存後に店舗通知だけが失敗した場合、顧客予約画面を再読み込みしても、24時間以内であれば「店舗への通知を再試行」から同じ予約番号の通知だけを再試行できる。

## 実装範囲

- 通知失敗時の予約内容・操作ID・顧客ID・失敗時刻をブラウザ内に保存する。
- 再読み込み後は、現在ログイン中の顧客と保存した顧客IDが一致する場合だけ再試行を復元する。
- 24時間を過ぎた記録、未来時刻、壊れた予約内容は復元せず削除する。
- 通知成功、または確定した通常エラーでは保存記録を削除する。
- 再試行では元の予約内容と操作IDを固定し、予約を新規作成し直さない。

## 検証範囲

- 同一顧客での再読み込み復元と通知成功後の表示解除。
- 別顧客で復元しないこと。
- 24時間経過、操作ID不一致、壊れた保存値の拒否。
- 通知失敗後の同一内容・同一操作IDによる再試行。
- 全回帰テスト1149件（成功1147件、失敗0件、任意PGlite 2件スキップ）、型検査、変更ファイルのlint、本番相当fixture build（93ページ）。

実DB、実LINE、実メールへの送信は行わない。DB migration、環境変数、認証方式の変更も含まない。
