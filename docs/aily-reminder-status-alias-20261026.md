# 予約前日リマインドの旧ステータス互換

## 利用者ができること

既存予約の確定ステータスに全角英字や空白が残っていても、対象日の前日リマインドLINEに含められます。未確定・取消・完了予約は送信対象にしません。

## 維持する送信保護

- スタッフ認証済みの所属サロンと対象日で予約を限定します。
- 送信履歴を確認できない予約は送信しません。
- 送信直前に予約を再取得し、内容が変わっていれば送信しません。
- 同じ予約と対象日は同じLINE再送キーを使い、応答喪失後の重複送信を防ぎます。
- 顧客・担当者・サロンの所属確認を維持します。

この変更にDB migration、環境変数変更、実LINE送信、本番公開は含みません。実データとPreviewでの確認は次回の統合後に行います。
