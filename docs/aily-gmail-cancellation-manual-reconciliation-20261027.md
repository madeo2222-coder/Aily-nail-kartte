# Gmail予約同期：手入力予約へのキャンセル収束（2026-10-27）

## 利用者が新しくできること

HPB／minimoの予約受付メールが同期されず、スタッフが予約を手入力した後にキャンセル通知だけ届いた場合でも、同じ予約を特定できれば手入力予約をキャンセルへ更新できる。別のキャンセル行を追加して元の予約を残す状態を防ぐ。

## 対象範囲

- 外部予約番号に一致する予約がまだ保存されていないキャンセル通知
- 正常な顧客電話番号から既存顧客を一意に特定できること
- 同じサロン、来店時刻付近、媒体、担当者、顧客が一致する手入力予約
- HPB／minimo共通

DB schema、migration、認証、環境変数、LINE送信は変更しない。

## 保護条件

- 電話番号が非公開・不明、顧客候補が複数、または手入力予約の顧客が異なる場合は、その予約をキャンセルしない。
- 同時刻に候補が複数あっても、既存顧客との紐付けで一意に選べる予約だけを更新する。
- 更新時に顧客、担当、日時、メニュー、状態、メモが別操作で変わった場合は、スタッフの変更を上書きせず停止する。
- 手入力メモを保存し、外部予約番号とキャンセル通知本文を同じ予約へ記録する。再試行は同じ予約へ収束する。
- 対応する手入力予約がない先行キャンセルは、従来どおり決定的IDのキャンセル予約として保存する。

## 受入条件

1. 同一顧客の手入力予約がキャンセルへ更新され、新しい予約行を追加しない。
2. 保存後の再試行で追加更新・追加行を発生させない。
3. 異なる顧客、電話番号なし、複数候補、同時変更では誤った予約を更新しない。
4. 対象手入力予約がない先行キャンセルと、予約番号で特定済みの通常キャンセルを維持する。
