# HPB・minimo 遅延同期の終了時刻照合（2026-10-30）

## 利用者ができること

スタッフが同じ顧客の近い時刻に複数の手入力予約を作成していた場合でも、HPB・minimo の予約メールに含まれる終了時刻と一致する予約が1件なら、その予約へ同期できます。終了時刻まで一致する候補が複数ある場合は、従来どおり誤更新を避けて同期を停止します。

## 変更範囲

- 開始時刻の前後5分という既存の候補検索範囲は維持する。
- 顧客・媒体・担当の既存条件で候補が複数残った場合だけ、メールの終了時刻（前後5分）を追加の判定に使う。
- 候補が1件の場合、終了時刻がない場合、不正な終了時刻の場合の既存動作は変えない。
- 終了時刻まで一致する候補が複数ある場合は同期を停止する。

DB migration、認証、環境変数、LINE・メール送信、実データの変更はない。

## 受入条件

1. 同じ顧客・同じ媒体の候補が複数あっても、終了時刻が一致する1件だけを更新する。
2. 終了時刻が一致する候補が複数なら更新しない。
3. 顧客・媒体・担当・キャンセル状態による既存の安全条件を維持する。
4. HPB・minimo の通常同期、キャンセル、再実行、競合保護の回帰テストが成功する。

## 検証範囲

- 終了時刻で1件へ絞る単体テスト
- 終了時刻まで複数一致した場合の安全停止テスト
- HPBメールから手入力予約を更新する同期経路テスト
- 全自動テスト、型検査、lint、ローカル production build
