# 来店後の施術写真案内LINE 安全化

## 対象業務

スタッフが対象日（必要なら顧客も指定）の来店者へ、施術写真を確認できる顧客マイページの案内をLINE送信する経路。

## 今回つないだ範囲

- スタッフ認証に所属サロンを必須化
- 対象日の来店一覧、顧客取得、送信直前の来店再確認を同一サロンに限定
- 顧客指定を受けても、所属サロン条件を外さない
- 実在する YYYY-MM-DD だけを受け付け、異常値では管理クライアントを作成しない
- line_notification_logs を送信前に確認し、確認エラー時は送信を止める
- 来店ID・通知種別・対象日から安定したLINE再試行キーを生成
- LINE応答喪失後の再実行でも同じキーを使い、受付済み409だけを成功回収
- LINE受付後の通知ログ保存失敗を成功扱いで隠さず、unrecordedCount で通知
- 送信準備中に来店の顧客・日付・サロンが変わった場合は送信しない

## 確認した受入条件

- 別サロンの来店・顧客を送信対象にできない
- 同じ来店・対象日への再実行で重複送信しない
- 送信履歴を確認できない場合は安全側で停止する
- LINE受付結果が不明でも再実行時の二重送信を避けられる
- LINE受付済みなのに記録保存できなかった状態を運用者が判別できる
- 認証失敗時はリクエスト本文、管理DB、LINEへ進まない
