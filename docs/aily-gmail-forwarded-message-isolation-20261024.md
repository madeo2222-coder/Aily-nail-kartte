# Gmail転送メールの予約本文分離（2026-10-24）

## 利用者への変更

Gmail予約同期で、現在のメールに別メールが `.eml` 形式で添付されている場合、添付メール内の予約内容を現在の予約へ混ぜないようにした。

Gmail APIでは、添付メールがファイル名や `Content-Disposition: attachment` を持たず、`message/rfc822` の入れ子として返ることがある。従来はその入れ子の本文も現在のメール本文として収集し、異なる予約番号・顧客・日時を同時に解析する可能性があった。今回、`message/rfc822` を添付メールの境界として扱い、その配下を同期対象から除外する。

## 確認内容

- 現在のメール本文と、別の予約内容を持つ `message/rfc822` 添付を同時に与えた
- 現在のメール本文だけが解析・同期されることを確認した
- 添付メール本文が解析文字列へ連結されないことを確認した
- 添付データを余分に取得しないことを確認した

## 変更しない範囲

- Supabaseのschema、migration、RLS、データは変更しない
- Gmail OAuth、環境変数、LINE通知、実顧客送信は変更しない
- `.eml` 添付自体を予約として同期する機能は追加しない

実Gmailアカウントでの転送メール受信から予約再表示までの確認は未実施。Preview反映後も、通常の予約メールが同期され、添付された別メールが混入しないことを許可されたテストメールで確認する必要がある。
