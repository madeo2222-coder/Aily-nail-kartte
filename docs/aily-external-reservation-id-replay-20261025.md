# 外部予約番号の旧表記再同期

## 対象

HPB／minimoメールの予約番号を正規化した後も、以前に小文字・全角表記で保存された同じ外部予約を再同期できるようにする。

## 変更

- 外部予約番号をNFKC正規化・大文字化して比較し、半角／全角・英字大小文字の差を同一として扱う。
- 予約番号から作る新規予約・顧客の決定的IDにも同じ正規化を適用する。
- DB読取は外部予約のメモキーで候補を絞り、アプリ側で予約番号行を完全一致させる。
- DB候補取得では旧メモの半角／全角ID・コロン差を許容し、完全一致判定は正規化後の行単位で行う。
- 候補が1,000件を超えても全ページを読み、後続ページの既存予約や重複を見落とさない。途中ページの読取失敗時は保存せず停止する。
- 正規化後に同じ番号となる予約が複数ある場合は、誤更新せず同期を停止する。

## 検証範囲

旧形式の全角・小文字minimo予約IDが保存された予約を、半角・大文字の再送メールで更新できることを自動テストで確認する。類似する長いIDやPostgRESTのパターン文字を含む別IDは一致させない。

実Gmail検索、Aily実DBへの保存・再表示は未検証。本変更にDB migration、権限、環境変数、外部送信の変更はない。
