# 手動予約メール同期の件名対応（2026-10-22）

## 利用者ができること

Gmail自動同期を利用できない場合の手動同期で、メール本文に加えて件名も貼り付けられる。件名にだけ「キャンセル」と記載されたHPB・ミニモ通知も、予約追加ではなくキャンセルとして既存の解析処理へ渡せる。

本文だけを使う従来の手動同期もそのまま利用できる。

## 操作

1. `/hpb-mail-sync-test` を開く。
2. 「メール件名」に通知メールの件名を貼り付ける。キャンセル通知では入力を推奨する。
3. 「メール本文」に通知メール本文を貼り付ける。
4. 「予約メール本文を同期テスト」を押す。

## 変更範囲

- 手動同期画面から件名と本文を送信する。
- スタッフ認証済みの手動同期APIが件名を既存の `syncHpbMailText` に渡す。
- 本文が空の場合の拒否、共有ログインを含む既存スタッフ認証、二重操作防止は維持する。

DB migration、権限、環境変数、Gmail接続、実顧客への通知送信は変更しない。

## 未検証範囲

実Gmail、Aily実DB、実顧客データ、実顧客へのLINE・メール送信を使った確認は行わない。Preview反映後の現場確認では、許可されたテスト通知を使い、キャンセルが新規予約として登録されないことを確認する。
