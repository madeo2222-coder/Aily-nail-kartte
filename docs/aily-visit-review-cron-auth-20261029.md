# 来店後施術写真案内LINEのCron認証修正（2026-10-29）

## 利用者が新しくできること

Vercel Cronから当日来店客への施術写真案内LINE処理を起動できる。手動実行のPOSTは従来どおりスタッフ認証と所属サロンを必要とする。

## 修正範囲

- 定期実行用GETをスタッフセッション認証から`CRON_SECRET`認証へ変更した。
- 定期実行は、既存migrationで確認済みのAily Nail StudioのID・名称・`active`状態がすべて一致するときだけ送信処理へ進む。
- Cron secret不一致、対象日不正、サロン確認失敗では、予約・来店読取やLINE送信より前に停止する。
- 既存の対象日、顧客・サロン紐付け、送信履歴、来店再読取、LINE再送キーの確認は維持した。

## 受入条件

- 正しいBearer secretを持つGETは、確認済みサロンだけを対象に来店情報を取得する。
- secretの欠落・不一致では401となり、DB読取とLINE送信を行わない。
- 確認済みサロンが存在しない、無効、または定義と異なる場合は503となり、来店取得とLINE送信を行わない。
- スタッフからのPOSTは従来どおりスタッフ認証と所属サロンで制限される。

## 検証限界

自動テストは架空データとモック送信で行う。Aily実DBのサロン状態、Vercel本番環境の`CRON_SECRET`、実LINE送信、実顧客への到達は確認しない。env/secret、DB、Vercel設定は変更しない。
