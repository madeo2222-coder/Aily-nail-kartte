# HPB区切り入り予約番号の予約元判定修正（2026-10-31）

## 対象

- 転送等で件名が一般化したHPB予約メールの予約元判定
- 実DB変更、実LINE／メール送信、環境変数変更、本番公開は含まない

## 問題

HPB予約番号の英字・数字間に空白やゼロ幅文字が混ざった場合、予約番号解析は正規化できるようになっていた。一方、その前段の予約元判定は連続した英数字だけをHPBの構造化番号として認識していた。

そのため、転送で件名が「ご予約内容のお知らせ」のように一般化し、顧客要望に「ミニモ」という語が含まれると、HPB予約をミニモ予約として誤判定して同期を停止する可能性があった。

## 変更

- HPB予約元判定でも、既存形式（英字1〜4文字＋数字6文字以上）の文字間に通常空白・タブ・ゼロ幅文字を許容する
- 後続する別の英数字がある不正値を、HPBの構造化予約番号として部分採用しない
- 一般化した件名と「ミニモ」を含む自由記入が同時にあっても、HPB予約番号を優先してHPB同期へ進める

## 受入条件

- `Ａ １ ２３ ４５６`（ゼロ幅文字混在）をHPBの構造化予約番号として判定する
- 顧客要望に「ミニモ」が含まれても予約元はHPBとなる
- 正規化後の `A123456` で既存予約へ一致し、追加登録ではなく更新へ進む
- 関連テスト、全回帰テスト、型検査、lint、fixture環境のNext本番buildが成功する
