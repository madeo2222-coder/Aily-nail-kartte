# HPB予約メールの日本語件名判定（2026-10-31）

## 利用者への影響

HPB予約メールの件名が「サロンボード」「ホットペッパービューティー」「ホットペッパーBeauty」の日本語表記でも、本文の備考・要望・メニューに含まれる「ミニモ」という語で媒体を誤判定しない。

これにより、予約番号を解析できず同期が止まるケースを減らし、スタッフによる再入力と時間差重複を防ぐ。

## 変更範囲

- 日本語表記のHPB件名を、本文中の自由入力語より強い媒体判定として扱う。
- 件名で媒体を特定できないメールの従来判定は維持する。
- DB、権限、環境変数、Gmail設定、実メール送信は変更しない。

## 検証範囲

- 3種類の日本語HPB件名について、本文の顧客要望に「ミニモ」が含まれてもHPB予約として既存行を更新する。
- 既存のHPB／ミニモ予約受付、変更、キャンセル、遅延同期、重複防止の回帰テストを実行する。

実Gmail、実Supabase、実顧客データでの同期は未実施。
