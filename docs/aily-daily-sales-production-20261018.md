## 利用方法と受入条件

- スタッフホーム `/dashboard` の売上カード上にある「日別売上の表示日」で日付を選ぶ。「昨日」「今日」や前日・翌日のボタンでも切り替えられる。
- 選択日の登録済み来店金額の合計と来店数を表示する。日付は日本時間。今月の売上と今日の予定は変わらない。
- 来店記録がない日は 0 円・0 件と表示する。読取失敗や不完全な応答は 0 円として扱わず、取得失敗と再試行を表示する。
- 日付を続けて変えた場合、以前の日付の遅い応答を採用しない。
- 既存 Supabase クライアントによる SELECT のみ。既存の集計と同じ `visits.visit_date` と `visits.price` を使う。
