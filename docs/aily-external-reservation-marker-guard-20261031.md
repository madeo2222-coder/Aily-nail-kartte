# 予約メモの予約サイト名による外部予約誤判定を修正（2026-10-31）

## 対象

- スタッフの予約確定、別日時提案、確認LINE／メール、編集、キャンセル
- 顧客アプリの予約変更・キャンセル申請
- 実DB変更、実LINE／メール送信、環境変数変更、本番公開は含まない

## 問題

顧客アプリから作成した通常予約でも、自由記入メモに「ミニモで見たデザイン」「ホットペッパーの写真を参考にしたい」などと書かれていると、外部同期予約と誤判定して確定や別日時提案などを停止していた。

## 変更

- 外部予約の判定は、`source` に記録されたHPB／minimo、または同期処理が保存する `HPB予約番号`／`ミニモ予約ID` マーカーに限定
- 予約サイト名だけが自由記入メモに含まれる顧客アプリ予約は通常予約として扱う
- 全角英数字やマーカー内の空白を正規化し、既存の外部同期予約の拒否を維持
- 同じ判定を使う7つの予約業務APIで挙動を統一

## 受入条件

- 顧客アプリ予約の自由記入メモに予約サイト名があっても、確定・別日時提案・通知・編集・キャンセルが進む
- `source` がHPB／minimoの予約は引き続きNaily側で変更しない
- `HPB予約番号`／`ミニモ予約ID` を持つ既存同期予約も引き続きNaily側で変更しない
- 最新内容照合、再送防止、二重送信防止、サロン所属制限を維持する
