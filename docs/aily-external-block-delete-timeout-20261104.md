# 外部予定削除の待機上限（2026-11-04）

## 対象業務

予約カレンダーでHPB・minimoなどの外部予定ブロックを削除する操作。

## 変更

- 削除APIのブラウザ待機を15秒で終了する。
- 削除結果が不明な場合は既存どおりカレンダーを再取得し、予定が残っている場合だけ再操作するよう案内する。
- 同じ予定の削除中に別の削除要求を送らない既存ロックを維持する。

## 受入条件

1. 正常応答では削除後のカレンダーを再表示する。
2. 明示失敗ではAPIのエラーを表示し、再操作を可能にする。
3. 応答喪失または15秒の待機超過ではカレンダーを再取得し、削除済みなら予定を表示しない。
4. 削除処理中の連打では同じ予定へ2件目を送らない。

## 未検証範囲

- Aily本番Supabaseへの実書込み
- 認証済みスタッフ端末での削除・再表示
- 別端末からの同時更新
