# 予約確定メール再試行の再読み込み復旧

## 利用者・目的

スタッフが予約確定後のメール通知だけ一時失敗したとき、予約一覧または予約編集画面を再読み込みしても、安全な再試行期限内なら作業を続けられるようにする。

## 今回の変更

- メール通知APIが案内した再試行期限、操作名、案内文を予約単位でブラウザに保存する。
- 予約一覧と予約編集画面の再読み込み時に保存内容を復元する。
- 再試行で一時失敗しても最初の期限を延長しない。
- 送信成功、意図した送信スキップ、期限切れ、壊れた保存値では再試行情報を削除する。
- 予約編集画面で確定状態ではないと確認した場合も保存情報を削除する。
- 送信API側の既存Resend idempotency key、予約・顧客・担当・サロンの送信直前再読取は変更しない。

## 受入条件

1. 申請中予約を確定し、メール通知が一時失敗または応答不明になる。
2. 予約一覧または予約編集画面を再読み込みする。
3. 確定済み予約に「確定メールを再試行」が再表示される。
4. 最初の案内から24時間以内に再試行でき、再試行しても期限が延長されない。
5. 成功後または期限切れ後に再読み込みすると、再試行ボタンは表示されない。
