# 顧客詳細の次回予約ステータス正規化

## 利用者ができること

- スタッフが顧客詳細を開いたとき、全角英字や空白を含む旧データの「完了」予約を次回予約として誤表示しない。
- 次回予約の状態名を、予約一覧などと同じ共通ルールで「予約確定」などの日本語表示に揃える。

## 変更範囲

- 予約状態の共通判定に、`completed` / `完了` とその全角・空白表記を扱う完了判定を追加した。
- 顧客詳細の次回予約抽出と状態表示を共通判定へ切り替えた。
- DB、migration、環境変数、認証方式、外部送信、本番環境は変更していない。
