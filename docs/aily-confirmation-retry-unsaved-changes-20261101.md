# 予約確定通知の再試行前に未保存変更を確認

## 利用者ができること

予約確定済みの予約を編集している途中に「確定LINEを再試行」または「確定メールを再試行」を押した場合、保存前の画面内容と保存済みの通知内容が食い違う可能性を画面で確認できます。

## 変更内容

- 店舗、顧客、担当者、メニュー、日時、状態、メモのいずれかに未保存変更がある場合、確定LINEと確定メールの再試行を送信前に停止します。
- 再試行の確認ダイアログ、ブラウザ保存済みの再試行状態確認、通知API呼び出しより前に停止します。
- 予約確定済み表示へ、先に変更を保存するか最新情報を再読み込みする案内を表示します。
- 別日時LINE依頼の既存ガードと同じ予約差分判定を共有します。

## 受入条件

1. 予約確定済みの予約で日時などを変更し、保存せず確定LINEまたは確定メールを再試行する。
2. 外部通知は実行されず、保存または再読み込みの案内が表示される。
3. 変更を保存するか最新情報を再読み込みした後は、既存の再送防止条件に従って再試行できる。
