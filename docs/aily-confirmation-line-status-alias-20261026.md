# 予約確定LINEの旧ステータス互換

## 利用者ができること

過去データに全角英字や空白を含む予約確定ステータスが残っていても、スタッフは予約一覧・編集画面から予約確定LINEを安全に再試行できます。

## 変更範囲

- 予約確定LINE APIの確定済み判定を、既存画面と同じNFKC正規化・空白除去・小文字化へ統一
- LINE再送キー、送信状態台帳、スタッフ認証、サロン所属、外部予約拒否は変更なし
- DB、migration、環境変数、実顧客データ、実LINE送信は変更なし

## 検証

- ` ＣＯＮＦＩＲＭＥＤ ` と ` 予 約 確 定 ` の両方で、送信状態を確保してLINE処理へ進むこと
- 既存の送信済み収束、失敗記録、同一retry key再試行、結果不明、外部予約・他サロン拒否の回帰テスト
- 型検査、lint、ローカルfixture build
