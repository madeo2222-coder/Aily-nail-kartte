# スタッフ予約キャンセルの応答待ち上限（2026-11-04）

## 利用者ができること

スタッフの予約編集画面でキャンセルを実行した後、保存やLINE通知の応答が失われても画面が無期限に処理中のままにならない。15秒で結果不明として案内し、同じ予約への重複操作を止めたまま再読み込みによる確認へ進める。

## 実装範囲

- スタッフ予約キャンセル `POST /api/reservations/:id/cancel`
- 更新・削除と同じ15秒待機上限を使用

- キャンセル済み予約の再実行ではLINEを再送しない既存API仕様を維持
