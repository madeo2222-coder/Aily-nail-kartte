# 予約一覧のステータス更新待機上限（2026-11-04）

## 対象業務

スタッフ予約一覧から行う「来店にする」「完了にする」などのステータス更新。

## 変更

- ステータス更新APIのブラウザ待機を15秒で終了する。
- 更新結果が不明な場合は既存どおり予約一覧を再取得し、保存後の応答喪失を画面上で照合する。
- 一覧の表示時点から予約内容が変わった場合の409競合、顧客ID・元ステータスの照合、連打防止を維持する。

## 受入条件

1. 正常応答では更新後の一覧を再表示する。
2. 競合応答では最新一覧を再表示し、古い画面の内容で更新しない。
3. 応答喪失または15秒の待機超過では最新一覧を再表示し、利用者へ結果確認を案内する。
4. 同じ予約の更新処理中は別の更新を送らない。
