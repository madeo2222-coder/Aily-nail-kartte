# 顧客の変更・キャンセル希望LINE重複防止

## 対象

顧客予約詳細画面の、確定済み予約に対する「変更希望を店舗へ送る」「キャンセル希望を店舗へ送る」。DB、認証、LINE設定は変更しない。

## 修正

- LINEが受理した変更希望とキャンセル希望を操作別にブラウザへ23時間保存する。
- 再読み込み後も送信済み表示を復元し、同じ操作の送信ボタンを戻さない。
- 別タブで先に送信された場合に備え、送信直前にも保存状態を再確認する。
- LINEの失敗または応答不明ではロックせず、既存の安定したLINE retry keyによる同内容の安全な再試行を維持する。
- 変更希望の送信済み状態はキャンセル希望を妨げず、キャンセル希望の送信済み状態も変更希望を妨げない。

## 検証範囲

成功時の保存、再読み込み後の復元、操作別の分離、23時間後の失効、失敗時の再試行維持、画面での送信ボタン置換を自動テストする。

## 未検証

実顧客へのLINE送信、Aily実DB、認証済み実端末の通し操作は未実施。ブラウザ保存による保護は同一ブラウザ内に限られ、サーバー側のLINE retry keyによる重複防止は既存実装を使用する。
