# HPB／minimo手入力予約照合の全件読取

## 利用者ができること

HPB／minimoの予約メールが遅れて届いたとき、同じ時間帯の手入力予約候補がSupabaseの1回の返却上限を超えていても、後半にある一致予約を再利用できる。

- 一致予約を見落として別の予約を作ることを防ぐ。
- 全候補を読み終えてから、顧客・担当・媒体を使って一意判定する。
- 途中ページを取得できなかった場合は、予約を追加・更新せず停止する。
- 新規予約とキャンセル通知の手入力予約照合に同じ保護を適用する。

## 変更範囲

- 手入力予約の日時範囲検索を、予約ID昇順のページ読取へ変更した。
- 1ページ1,000件として、1,000件未満のページまで取得する。
- DB schema、migration、認証、環境変数、外部送信は変更していない。

## 受入条件

1. 1,001件目の一致予約を見つけ、既存予約を更新する。
2. 2ページ目の読取に失敗した場合、書込みを行わない。
3. 既存の顧客一致、担当者保護、複数候補時の安全停止を維持する。
