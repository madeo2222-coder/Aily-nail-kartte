# 予約確定メールの別タブ再送表示修正（2026-11-03）

## 今回の範囲

- 予約一覧と予約編集画面で、別タブが確定メールを送信中の場合に送信中表示へ同期し、古い再試行ボタンを隠す。
- 送信中ロックまたは再試行期限が切れた時点で、開いたままの画面を自動更新する。
- 別タブの送信結果が確定したら、保存された最新状態へ同期する。
- 既存の送信API、冪等性キー、5分の送信中ロック、24時間の再試行期限は変更しない。

## 受入条件

1. 同じ確定済み予約を2つのスタッフ画面で開く。
2. 一方で確定メールを再試行すると、もう一方は送信中表示になり再試行ボタンが消える。
3. 送信結果が確定すると、もう一方も成功時は表示が消え、再試行可能な失敗時は最新の再試行表示になる。
4. 送信中ロックまたは再試行期限が切れた後、画面を再読み込みしなくても保存状態に合う表示へ戻る。
