# Gmail予約メールの処理順固定（2026-10-21）

## 利用者・目的

HPB／minimoの予約メールを同期するスタッフが、Gmail検索結果の並び方に左右されず、予約受付→変更／キャンセルの実際の時系列どおりに予約を反映できるようにします。

## 今回の納品範囲

- Gmail一覧の推定順ではなく、取得した各メールの `internalDate`（受信時刻）で古い順に処理
- 同じ受信時刻の場合は取得済みの順序を維持
- 受信時刻が取得できないメールは、誤った順序で同期せず失敗として結果へ表示
- 既存の最大500通、10ページ、本文5並列取得、部分失敗表示を維持

## 受入条件

1. Gmail検索結果が時系列どおりでないfixtureを同期する
2. 予約メール本文の取得は従来どおり並列で完了する
3. 実際の受信時刻が古いメールから順に予約同期される
4. 受信時刻がないメールはDB同期されず、失敗件数として表示される

## 残件

確認版へ統合後、許可されたテスト用の予約受付メールとキャンセルメールで、受付→キャンセルの順に反映されることを実接続で確認します。Aily実DB、実Gmail、実LINE、本番では未確認です。

## 次の納品予定

最新Vercel試行から6時間経過後の単一Previewバッチに、先行する未反映予約同期修正とまとめます。反映直前に全環境の最新試行と統合branchを再確認します。

## 必要な本人操作

現時点ではありません。DB変更、migration、接続切替、秘密情報の提出は不要です。
