# 予約キャンセル競合時の最新内容反映（2026-11-01）

## 利用者ができること

スタッフが予約編集画面を開いている間に、別端末や別操作で予約内容が更新されていた場合、古い内容のままキャンセルを続けず、最新の予約内容を同じ画面へ読み直して確認できる。

## 実装範囲

- キャンセルAPIが、表示時点から予約が変わった競合と書込み直前の競合を `stale_reservation` として返す。
- 予約編集画面はその競合だけを判別し、予約・顧客・スタッフ情報を再取得する。
- 再取得に成功した場合は、最新内容を確認してから再度キャンセルするよう案内する。
- 競合した操作ではキャンセル完了状態へ進まず、LINE通知処理も開始しない。
- その他のエラーでは従来どおり入力中の内容を維持する。

## 現場受入手順

1. 端末Aと端末Bで同じ予約の編集画面を開く。
2. 端末Aで予約日時などを変更して保存する。
3. 古い表示のままの端末Bでキャンセルする。
4. 端末Bに最新の予約内容が表示され、再確認を促す案内が出ることを確認する。
5. その操作ではキャンセル完了にならず、LINE通知が送られないことを確認する。
