# 顧客予約詳細の担当者取得失敗を誤表示しない修正（2026-10-28）

## 利用者への効果

顧客が予約詳細を開いたとき、担当スタッフ情報の取得に失敗しても「指名なし」と誤表示しません。予約自体の取得失敗も「予約が見つからない」状態と区別し、再読み込みできるエラーとして表示します。

## 修正内容

- 担当スタッフの読取エラーを無視せず、安全なエラー文でAPIエラーを返す。
- 担当スタッフIDがあるのに該当スタッフが存在しない場合は「担当者情報なし」と表示し、未指名予約と区別する。
- 担当スタッフは予約と同じサロンに限定して取得する。
- 予約読取エラーに含まれるデータベース内部メッセージを顧客画面へ返さない。

## 確認条件

- 予約読取失敗が404や空予約として表示されないこと。
- スタッフ読取失敗が「指名なし」と表示されないこと。
- スタッフIDの参照先がない場合は「担当者情報なし」と表示されること。
- 通常の予約詳細、変更希望、取消希望、LINE通知の既存動作が維持されること。
