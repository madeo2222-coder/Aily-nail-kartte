# Gmailキャンセル同期：現場の担当変更を維持した予約収束

## 利用者ができること

HPB／minimoの受付メールを取り逃がして手入力した予約で、現場が担当者を変更した後にキャンセル通知が届いても、同一顧客の予約をキャンセルへ更新できる。

- メール記載の担当者と手入力予約の担当者が異なっても、予約側の顧客IDがメールから安定照合した顧客IDと完全一致するときだけ更新する。
- キャンセル更新では現場が設定した担当者を上書きしない。
- 顧客未設定、別顧客、複数候補の場合は更新もキャンセル行の追加も行わず停止する。
- 通常の新規・変更予約では、別担当者へ変更済みの手入力予約を従来どおり自動採用しない。

## 変更範囲

- 手入力予約を探す共通関数へ、顧客ID完全一致時だけ担当差異を許容する明示オプションを追加した。
- このオプションはキャンセル収束だけで使用し、新規・変更予約には適用していない。
- DB schema、migration、認証、環境変数、外部送信は変更していない。

## 受入条件

1. 有効なメール担当者と手入力予約の担当者が異なっても、同一顧客の1件だけをキャンセルへ更新する。
2. 保存済みの担当者IDは変更しない。
3. 別顧客の手入力予約は変更せず、安全停止する。
4. 複数候補、新規・変更予約、既存の同時変更保護を維持する。
