# HPB／minimo遅延同期の自由記入誤判定修正（2026-11-03）

## 利用者・目的

スタッフが先に手入力した予約へHPB／minimoの予約メールが後から届く運用で、同じ予約を二重作成しないための修正です。

## 修正した問題

手入力予約の自由記入に「ミニモで見たデザインを希望」「ホットペッパーの写真と同じ色を希望」など予約サイト名が含まれると、その文言を予約元の印として扱っていました。そのため、実際の予約元が別サービスの場合、顧客・日時・スタッフが一致する手入力予約を再利用できず、新規予約を作る可能性がありました。

## 変更内容

- 予約元の判定を、スタッフ登録画面が保存する構造化行 `外部予約種別：...`、予約元を示すメニュー名、既存の明示的な電話受付メモに限定しました。
- 顧客の自由記入に含まれる予約サイト名は、予約元の印として扱いません。
- 予約元が構造化されている手入力予約、別顧客の予約、複数候補、キャンセル済み予約を拒否する既存の保護は維持します。
- DB、migration、認証、通知設定の変更はありません。

## 受入条件

同一顧客・日時・スタッフの手入力予約に別サービス名を含む自由記入があっても、後着したHPB／minimoメールは既存予約を更新し、新しい予約行を作らないこと。構造化された別サービスの予約は再利用しないこと。
