# 予約確定LINEの文字数上限を送信前に確認する修正（2026-10-28）

## 利用者への効果

予約確定LINEの完成メッセージがLINEの文字数上限を超える場合、スタッフへ顧客名・サロン名・メニュー名・担当者名を短くするよう案内します。送信できない内容で通知台帳をclaimせず、LINE APIも呼びません。

## 修正内容

- LINEテキストの5000文字上限を、LINEと同じUTF-16コード単位で確認する。
- 上限超過を通知claimより前に検出する。
- 上限超過時は `message_too_long` と再入力案内を返す。
- 既存の店舗制限、確定状態確認、外部予約拒否、再送キー、結果不明時の再送防止は維持する。

## 確認条件

- サロゲートペアを含む完成メッセージをUTF-16コード単位で数えること。
- 5000コード単位を超える場合、通知claim、LINE送信、完了記録を実行しないこと。
- 上限内の確定通知は従来どおり送信処理へ進むこと。

## 反映範囲と未検証

Aily実DB、実顧客LINE、実機、Preview、本番は未検証・未変更です。DB migration、RLS、環境変数、実送信の変更はありません。
