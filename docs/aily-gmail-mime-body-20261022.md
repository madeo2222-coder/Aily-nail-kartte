# Gmail予約メール本文の形式差吸収（2026-10-22）

## 利用者・目的

HPB／minimo予約を同期するスタッフが、メール本文の形式がプレーンテキスト、HTML、multipartのどれでも、予約番号・氏名・来店日時を同じ形で取り込めるようにします。

## 今回の納品範囲

- HTMLの`div`、段落、表、改行をテキストの改行・区切りへ変換
- HTMLの主要な名前付き文字参照と数値文字参照を復元
- multipartにtext/plainとHTMLの両方がある場合はtext/plainを優先し、同じ本文の二重取込を防止
- ファイル名があるテキスト添付は予約本文へ混ぜない
- Gmail認証、検索条件、処理順、予約保存、通知は変更しない

## 受入条件

1. HTMLだけの予約メールを同期する
2. 予約番号、氏名、来店日時が別々の行として解析処理へ渡る
3. text/plainとHTMLを含む同一メールを同期する
4. 予約本文が1回だけ解析処理へ渡り、メモへ重複保存されない

## 実際に確認した業務

- `div`で区切られたHTML予約メールの本文を改行付きテキストへ変換
- multipart/alternativeではtext/plainだけを採用
- 認証、複数ページ取得、受信時刻順、取得失敗、部分成功の既存テストを維持
