# 顧客予約の確定状態表記揺れ対応

## 対象業務

確定済み予約を開いた顧客が、店舗へ変更希望またはキャンセル希望をLINEで送る操作。

## 修正内容

顧客予約APIで確定状態を判定するとき、既存のスタッフ画面と同様にNFKC正規化、空白除去、小文字化を行う。これにより、旧データに全角英字や前後空白を含む `ＣＯＮＦＩＲＭＥＤ` が保存されていても、予約詳細に変更希望・キャンセル希望を表示し、店舗への依頼を送れる。

予約申請中の直接編集・取消は既存DB RPCが受け付ける状態だけを維持した。予約状態やDB定義の書換え、migration、外部予約の制限、LINE本人認証、顧客ID紐付け、再送キーは変更していない。
