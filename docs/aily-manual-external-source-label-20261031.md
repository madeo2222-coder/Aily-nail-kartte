# 手入力した外部予約の予約元表示

## 利用者が新しくできること

スタッフが予約登録画面の「外部予約・ブロック」からホットペッパーまたはミニモを選んで登録した予定は、予約カレンダーでそれぞれ「HPB予約」「ミニモ予約」と表示される。

メール同期で取り込まれた予約は従来どおり「HPB同期」「ミニモ同期」と表示する。顧客メモにサイト名が書かれただけのNaily予約も、従来どおり「Naily予約」と表示する。

## 保持する動作

- スタッフが手入力した外部予約は同期予約として扱わず、既存どおり編集・削除できる。
- HPB／ミニモの予約番号を持つ同期予約の編集・削除保護は変えない。
- 顧客メモの自由文から予約元を推測しない。
- DB、認証、環境変数、外部送信は変更しない。

## 確認方法

1. スタッフの予約登録画面で「外部予約・ブロック」を選ぶ。
2. 予約元に「ホットペッパー」または「ミニモ」を選んで登録する。
3. 予約カレンダーを開き、予定の予約元バッジを確認する。

## 検証範囲

- 構造化された外部予約種別から表示用の予約元だけを判定するテスト
- 手入力予約が同期予約の編集保護対象にならない回帰テスト
- 手入力・同期済み・Naily予約の各バッジ表示テスト
- 型検査、lint、全自動テスト、ローカル本番ビルド

実DBへの登録、認証済みPreviewでの操作、実際のHPB／ミニモ同期はこのローカル検証には含まない。
