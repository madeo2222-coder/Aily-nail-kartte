# 別日時LINE依頼の店舗外読取を防ぐ修正（2026-10-28）

## 利用者への効果

スタッフが申請中予約へ別日時の入力を依頼するとき、最初の予約取得から認証済みスタッフの所属店舗に限定します。別店舗の予約IDが指定されても、店舗外の予約行を管理権限で読み取らず、通知状態の取得やLINE送信へ進みません。

## 修正内容

- 別日時LINE依頼APIの最初の予約取得へ、認証済みスタッフの `salon_id` 条件を追加する。
- 既存の予約スナップショット照合、外部予約拒否、顧客所属確認、LINE再送防止を維持する。
- 店舗条件が最初の予約取得に含まれることを回帰テストで固定する。

## 確認条件

- 最初の予約取得が予約IDと認証済み店舗IDの両方で絞られること。
- 同じ店舗の申請中予約は従来どおり通知処理へ進むこと。
- 古い画面、外部予約、送信済み、送信中、結果不明、LINE拒否の既存ガードが維持されること。

## 反映範囲と未検証

Aily実DB、実顧客LINE、実機、Preview、本番は未検証・未変更です。DB migration、RLS、環境変数、実送信の変更はありません。別日時依頼用DBオブジェクトの読取結果は回答待ちのままであり、このコード検証を実DB適用確認とは扱いません。
