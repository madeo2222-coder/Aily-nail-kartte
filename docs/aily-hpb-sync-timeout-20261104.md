# HPB・minimo予約同期の応答待ち上限（2026-11-04）

## 利用者が新しくできること

- 予約カレンダーの「予約今すぐ同期」でGmail同期APIが応答しない場合も、画面が無期限に「同期中」のまま残らない。
- 予約同期センターのGmail同期と手動メール本文同期も、同じ条件で結果確認案内へ移る。
- 結果が不明な場合は既存の共有ロックを維持し、別タブ・再読み込み後を含めて同じ同期を重ねて実行しない。

## 実装範囲

- Gmail同期と手動メール同期のブラウザ待機を60秒で終了する共通リクエストを追加した。
- 明示的なAPI失敗・部分成功・正常完了では、従来どおりロックを解除して再試行可能にする。
- 応答喪失・不正JSON・タイムアウトでは、従来の結果不明表示と反映状況の確認手順を使用する。

## 受入条件

1. 正常応答では同期結果を表示し、次の同期を実行できる。
2. 部分成功または明示的な失敗では、内容を表示して再試行できる。
3. 60秒応答がない場合は結果不明となり、同じGmail同期または同じ手動メールの重複実行を防ぐ。
4. 予約カレンダーと予約同期センターでGmail同期の結果不明ロックを共有する。
