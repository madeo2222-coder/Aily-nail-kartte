# 別日時入力LINEの再送ロック

## 対象

スタッフ予約編集画面の「別日時をLINEで依頼」。DB、認証、LINE設定は変更しない。

## 修正

- LINE送信済み、送信結果不明、送信済みだが台帳保存失敗、安全な再送期限切れをブラウザに23時間保存する。
- 上記状態では再読み込み後も送信ボタンを戻さず、送信済みまたは送信履歴確認の案内を表示する。
- サーバーが失敗を台帳へ保存し `retryable: true` を返した場合と、LINE未連携の場合は再試行を妨げない。
- 既存のDB送信台帳、LINE retry key、スタッフ個別認証、予約スナップショット照合はそのまま使う。
