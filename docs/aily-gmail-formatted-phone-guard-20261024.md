# Gmail予約の電話番号表記ゆれ・誤紐付け防止（2026-10-24）

## 利用者に変わること

HPB／minimo予約メールの電話番号が `+81 (0)90-...`、全角数字、空白、括弧を含む場合も、既存顧客の国内電話番号と同一として照合する。

従来はメール解析が番号を途中で切り落とし、既存顧客を見つけられず外部予約用の別顧客を作成する可能性があった。今回、電話番号行を最後まで読み、国内・国際表記を既存の顧客照合処理へ渡す。

文字が混入した番号、短すぎる番号、長すぎる番号は顧客・予約の書込み前に停止し、部分的な番号で別顧客を作成しない。

## 納品範囲と受入条件

1. `+81 (0)90-0000-0000` を `09000000000` と同一として既存顧客へ紐付ける。
2. 全角数字・全角記号・空白入りの番号を同一顧客へ紐付ける。
3. 電話番号がラベルの次行にあるメールも解析する。
4. 英字などが混入した電話番号はDBアクセス前にエラーにする。
5. 既存の同姓同名・複数顧客・別サロン・キャンセル・同時更新の保護を維持する。
