# HPB／minimoキャンセル先行時の顧客履歴紐付け（2026-10-27）

## 対象業務

HPB／minimoの予約受付メールより先にキャンセル通知が届き、対応する予約がまだ存在しない場合でも、キャンセル済み予約を保存して後着メールによる再作成を防いでいる。

従来は電話番号で顧客を一意に特定できても、作成したキャンセル済み予約へ `customer_id` を保存していなかった。そのため、重複防止は機能していても顧客履歴から確認できない状態が残った。

## 今回の変更

- 電話番号で顧客を一意に特定できた場合だけ、先行キャンセル予約へ顧客IDを保存する。
- 電話番号がない、または安全な顧客キーがない通知は顧客へ推測で紐付けない。
- 既存のキャンセル再送冪等性、後着予約メールの再作成防止、別サロン拒否を維持する。
- DB migration、権限、環境変数、Gmail設定は変更しない。
