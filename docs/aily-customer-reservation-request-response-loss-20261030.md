# 顧客の変更・キャンセル希望LINE 応答喪失後の再試行

## 対象業務

確定済み予約の顧客が、マイページから店舗へ変更希望またはキャンセル希望を送る操作。

## 修正内容

- ブラウザが店舗LINE送信の応答を受け取れなかった場合、送信した操作種別と入力内容を端末内へ23時間だけ保存する。
- 再読み込み後も「同じ変更希望を再試行」「同じキャンセル希望を再試行」を表示する。
- 再試行時は入力欄を固定し、保存済みの同じ内容だけを送る。サーバー側の既存LINE retry keyへ収束させる。
- 明確な成功、入力不備、再試行不能の応答を受け取った場合は再試行情報を削除する。
- DB migration、認証、env、実送信の変更はない。

## 受入条件

1. 変更希望またはキャンセル希望の送信中に通信切断・応答解析不能が発生しても、同一端末の再読み込み後に同じ内容を再試行できる。
2. 再試行前に内容を書き換えて別のLINEを追加送信できない。
3. LINE APIの一時失敗として記録された応答でも同じ内容を再試行できる。
4. 成功または安全に再試行できない結果では再試行情報が残らない。

## 未検証

Aily実DB、通常顧客LINE認証、実店舗LINE送信、別端末をまたぐ操作は未検証。確認版へ反映する場合は、Aily全体の6時間間隔と単一統合バッチ条件を維持する。
