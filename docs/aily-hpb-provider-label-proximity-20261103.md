# HPB/minimo 遅延同期の提供元ラベル境界修正（2026-11-03）

## 対象業務

スタッフが先に手入力した予約へHPB/minimoメールが遅れて届いたとき、同じ顧客・同じ時間帯の予約へ収束させ、重複行を作らない処理。

## 問題

提供元名を含む通常のメニューや顧客メモは外部予約メタデータとして扱わないよう修正済みだったが、同じ文中の離れた位置に「予約」があると提供元ラベルに誤判定される余地が残っていた。例えば「予約時にミニモで見たデザインを希望」はHPBの手入力予約にもなり得るが、minimo予約として除外され、遅延同期が既存行へ収束しない可能性があった。

## 修正

- 提供元名と「予約」「受付」「外部」「booking」等が一つのラベルとして隣接する表記だけをメニュー由来の提供元として認識する。
- `外部予約：HPB`、`HPBからの予約`、`予約元：ミニモ` などの明示表記は維持する。
- 先頭メモは構造化された `外部予約種別：...` と、既知の「HPB/minimoから電話...」形式を維持する。
- 「予約時にミニモで見たデザイン」のような通常文は別提供元の予約と判定せず、同一顧客の遅延同期候補に残す。
