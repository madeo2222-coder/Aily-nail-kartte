# Gmail予約メールの全角英数字互換

## 対象

HPB／minimo予約メールが転送・コピーされた際、予約番号、予約ID、来店日時、施術時間、電話番号の英数字や記号が全角へ変換される場合の同期取りこぼしを修正する。

## 変更

- 構造化項目を解析する本文だけをNFKC正規化する。保存するメール原文は変更しない。
- HPB予約番号は全角英数字と小文字を受け付け、既存メモと同じ大文字の識別子へ統一する。
- minimoの全角サービス名・予約ID・日時・所要時間・電話番号を既存の半角表記へ統一して照合する。
- 日付妥当性、所要時間上限、電話番号長、サロン所属、重複予約の既存検証は維持する。

## 検証範囲

- 全角HPB予約番号と日時が、同じ予約番号の既存予約へ更新されること。
- 全角minimoサービス名・予約ID・日時・所要時間・電話番号が、同じ予約IDの既存予約へ更新されること。
- 保存メモには受信したメール原文が残ること。

実Gmail、Aily実DB、実顧客データでの保存・再表示は未検証。本変更にDB migration、権限、環境変数、外部送信の変更はない。
