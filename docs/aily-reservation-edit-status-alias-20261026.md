# 予約編集画面の状態表記揺れ対応

## 対象業務

スタッフが予約一覧またはスタッフホームから予約編集画面を開き、確定済み予約の内容を確認・更新する操作。

## 修正内容

予約編集画面だけに残っていた状態の完全一致判定を、一覧・スタッフホームと同じ共通正規化へ変更した。NFKC正規化、空白除去、小文字化により、旧データに全角英字や前後空白を含む `ＣＯＮＦＩＲＭＥＤ` が保存されていても「予約確定」と表示し、申請中へ誤表示しない。

予約状態そのもの、許可する状態遷移、楽観ロック用の保存値、DB定義、外部予約制限、LINE通知は変更していない。更新APIへは引き続き読込時の生の状態を `expectedStatus` として送り、同時更新を検知する。
