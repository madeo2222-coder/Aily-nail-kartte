# 予約カレンダーの予約元表示修正（2026-10-31）

## 利用者が新しく確認できること

- Naily予約の顧客メモに「LINEで連絡」「Instagramの画像」「電話してください」などが含まれていても、予約元は「Naily予約」と表示される。
- 予約元にLINE、Instagram、電話が明示されている予約は、従来どおり各予約元で表示される。
- 外部予定は、タイトルやメモからLINE、Instagram、電話を補助判定する従来の表示を維持する。

## 変更範囲

- 予約カレンダーの予約元ラベル判定で、通常予約の自由記述をLINE・Instagram・電話の判定材料から除外した。
- 通常予約は予約データの `source` を使い、外部予定だけタイトル／メモの補助判定を使う。
- DB、migration、認証、環境変数、外部送信は変更していない。

## 受入条件

1. Naily予約のメモにLINE、Instagram、インスタ、電話を含めても「Naily予約」と表示される。
2. `source` がLINE、Instagram、phoneの予約は、それぞれ「LINE予約」「Instagram」「電話予約」と表示される。
3. 既存のHPB／ミニモ識別、予約状態、予約詳細表示に回帰がない。
