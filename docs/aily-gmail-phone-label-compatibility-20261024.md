# Gmail予約の電話番号ラベル互換性（2026-10-24）

## 利用者に変わること

HPB／minimo予約メールで、電話番号ラベルと番号が同じ行にあり、`電話番号 090-...` のようにコロンが省略された形式も既存顧客の電話番号として照合する。

直前の電話番号表記ゆれ対応では、コロン付き、ラベルの次行、国際表記、全角数字を安全に扱うようにした。一方、旧パーサーが受け付けていた同一行・コロン省略形式を取りこぼす可能性があったため、検証付きで互換性を戻した。

## 受入条件

1. `電話番号 090-0000-0000` を既存顧客の `09000000000` と照合する。
2. 英字混入、短すぎる番号、長すぎる番号は引き続きDBアクセス前に停止する。
3. コロン付き、ラベルの次行、`+81 (0)`、全角数字の既存対応を維持する。
4. 顧客候補が複数の場合の書込み停止、別サロン保護、予約再送防止を維持する。
