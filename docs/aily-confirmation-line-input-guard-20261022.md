## 修正内容

- `request.json()` が失敗した場合をHTTP 400として扱う。
- 本文がオブジェクトでない場合と、`reservationId` が空または文字列でない場合を送信処理前に拒否する。
- 予期しないDB/RPCエラーはサーバーログへ残し、ブラウザへ内部メッセージを返さない。
- 既存のスタッフ認証、店舗制限、確定済み判定、LINE再送キー、送信台帳、再試行条件は変更しない。
- DB、migration、env/secret、実LINE送信は変更しない。
