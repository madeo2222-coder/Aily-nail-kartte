# 予約確定メールの旧ステータス互換

## 利用者ができること

既存データに全角英字や空白を含む予約確定ステータスが残っていても、スタッフは予約確定メールを送信できます。対象は `confirmed` と `予約確定` の表記揺れだけです。

## 維持する送信保護

- 送信前に予約を再取得し、最初に読んだ内容から変更されていれば送信しません。
- Resend の冪等キーは予約IDと実際のメール内容から生成し、同じ内容の再送を収束させます。
- HPB・minimo由来の外部予約は引き続きNailyの予約確定メールを送信しません。
- スタッフ認証、サロン所属範囲、顧客メールアドレスの確認を維持します。

## 検証範囲

自動テストで全角英字と空白入り日本語の旧ステータス、未確定予約の拒否、外部予約の拒否、送信直前の変更検知、再送キーを確認します。

この変更にDB migration、環境変数変更、実メール送信、本番公開は含みません。実データとPreviewでの確認は次回の統合後に行います。
