# Gmail予約メール再処理の書込み防止（2026-10-23）

## 利用者に変わること

HPB／minimo の Gmail 同期は直近30日のメールを毎回読み直す。すでに成功した同一の予約メールが再度見つかった場合は、予約行を書き換えず「反映済み」として収束する。

これにより、初回同期後にスタッフが修正した顧客紐付け、担当、メニュー、予約日時を、過去の同じメールの定期再処理で戻さない。

## 対象範囲

- 同一の外部予約番号／IDが既存予約にある
- 保存済みのメール本文と今回の本文が同一
- 予約メールである（キャンセルメールは従来どおり別経路で処理）

日時・メニュー等が変わった新しいメールは同一本文ではないため、従来の照合・更新処理へ進む。

## 受入条件

1. 同一予約メールの再処理で `reservations` と `customers` へ書き込まない。
2. スタッフが同期後に修正した顧客、担当、メニュー、日時を維持する。
3. 変更された予約メールは通常の更新経路で反映できる。
4. キャンセル、新規予約、手入力予約との照合、並行更新保護は維持する。

## 変更しない範囲

- DB schema／migration／RLS／環境変数
- Gmail認証・cron設定
- 実 Gmail 取込、実DB書込み、実顧客通知
- main／本番環境
