# 顧客LINE依頼の古い再試行データを予約更新時に破棄

## 対象

顧客予約詳細で、変更希望またはキャンセル希望の店舗LINE送信結果が不明になり、ブラウザへ再試行内容が保存された後にスタッフが予約内容を更新した場合。

## 修正

- 保存済み再試行の予約revisionが現在の予約revisionと一致する場合だけ復元する。
- 予約revisionが変わった古い再試行データは読取時にブラウザ保存領域から削除する。
- 古い変更希望が新しいキャンセル希望を、古いキャンセル希望が新しい変更希望を妨げないようにする。
- 予約更新後は古い依頼文を入力欄へ戻さない。
- 同じ予約revisionの再試行、送信済みロック、重複LINE防止は維持する。

## 検証範囲

- 同じ予約revisionの再試行復元
- 異なる予約revisionの再試行破棄と保存領域の削除
- 期限切れ・壊れた保存データの破棄
- 変更希望／キャンセル希望を分けた再試行と送信ロック
- 型検査、lint、全回帰テスト、fixture設定のNext production build

実DB、通常スタッフ認証後の実データ、実LINE送信は未検証。DB migration、env/secret、本番公開は行わない。
