# スタッフ予約画面の外部同期判定修正（2026-10-31）

## 利用者ができること

Nailyから入った予約のメモに「ミニモで見たデザイン」や「ホットペッパーの写真」と書かれていても、スタッフは通常どおり予約確定、確定LINE再試行、予約編集を行える。予約カレンダーでも該当予約を「Naily予約」と表示し、外部カレンダー反映待ち一覧から誤って除外しない。

## 判定基準

- 予約元 `source` がHPBまたはminimoを明示している場合は外部同期予約とする。
- メモは `HPB予約番号` または `ミニモ予約ID` の構造化マーカーがある場合だけ外部同期予約とする。
- 全角・半角、大文字・小文字、マーカー内の空白差は正規化する。
- サイト名に触れただけの自由記述は外部同期予約としない。

共通判定を `lib/external-reservation-metadata.ts` に置き、予約一覧、予約編集、予約カレンダー、外部カレンダー反映待ち一覧から利用する。

## 受入条件

1. `customer-app` または `Naily` 予約のメモが「ミニモで見たデザインを希望」でも、予約確定または確定LINE再試行が表示される。
2. 同じ予約がカレンダーで `Naily予約` と表示され、`ミニモ同期` にならない。
3. 同じ予約が外部カレンダー反映待ち一覧に残る。
4. `HPB 予約 番号`、`ミニモ 予約 ID` のように空白を含む正式マーカーは、従来どおり外部同期予約として操作を制限する。
