# 予約確定の競合時に最新内容を自動反映（2026-11-01）

## 利用者ができること

スタッフが予約編集画面で確定操作をした直前に、別端末で同じ予約が更新されていた場合、画面へ最新の予約内容を自動で反映してから再確認を案内します。古い顧客・日時・担当・メニューの表示を残したまま確定や通知へ進みません。

## 実装範囲

- 予約確定APIは予約スナップショットの不一致と確定RPCの競合結果を `stale_reservation` として返す
- 予約編集画面は `stale_reservation` を受けると予約詳細を再取得し、最新内容を表示する
- 最新内容の再取得に失敗した場合は、元の競合エラーを表示して操作を止める
- 競合時は確定LINE・メール通知を呼び出さない

## 現場受入条件

通常のスタッフ認証で予約編集画面を開き、同じ予約を別端末で更新した後に古い画面から確定すると、最新内容が自動表示され、通知が送られないことを確認する。実DBを使うこの確認はPreview反映後の現場試用で行う。
