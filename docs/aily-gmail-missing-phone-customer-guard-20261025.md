# Gmail予約同期：電話番号欠落時の顧客誤紐付け防止（2026-10-25）

## 利用者への影響

- 電話番号がない新規HPB／minimo予約メールは、同名顧客への誤紐付けや連絡先のない重複顧客作成を避けるため、予約保存前に停止する。
- 同じ外部予約番号ですでに保存済みの予約は、既存の顧客紐付けを維持して更新できる。
- キャンセルメールの予約番号だけによる既存予約照合は維持する。

## 変更範囲

- `lib/hpb-mail-sync.ts`
  - 新規外部予約で電話番号が欠落している場合の書込み停止を追加
  - 既存外部予約の顧客リンク維持を優先する既存経路は変更なし
- `tests/hpb-mail-sync-customer-guard.test.mjs`
  - 電話番号なしの新規予約が同名顧客へ付かず、書込みも発生しないことを確認
  - 電話番号なしの既存予約更新が既存顧客を維持することを確認

DB schema、migration、RLS、環境変数、実データ、外部送信は変更していない。
