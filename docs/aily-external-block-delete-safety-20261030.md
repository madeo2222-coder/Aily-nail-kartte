# 外部予約ブロック削除の結果不明・連打対策（2026-10-30）

## 利用者が新しくできること

予約カレンダーから外部予約ブロックを削除した際、通信切断や応答欠損が起きてもカレンダーを安全に再読込して削除結果を確認できる。削除ボタンの連打や別要求との競合でも、既に削除済みなら成功へ収束する。

## 変更範囲

- 削除開始をブロックID単位で即時ロックし、再描画前の連打でもAPIを1回だけ呼ぶ。
- 応答本文を取得できない場合または通信結果不明の場合、書込みを繰り返さず予約カレンダーを読取再表示する。
- APIは対象が既に存在しない場合を削除済み成功として返す。
- 同時削除で先行要求が行を削除した場合、後続要求は再読取して削除済み成功へ収束する。
- 削除対象が残っている場合は成功とせず、カレンダー再読込を案内する。
- 既存行に対するスタッフ認証、サロン所属、サロンなし旧データの担当者所属確認は維持する。

DB migration、env/secret、実データ、実LINE・メール送信は変更していない。

## 受入条件

1. 同じ削除ボタンを再描画前に2回押しても削除APIは1回だけ呼ばれる。
2. 削除応答を失った場合はカレンダーを再読込し、同じ削除を自動再送しない。
3. 対象が既にない場合と、同時削除で先行要求が成功した場合は成功へ収束する。
4. 明示的な削除失敗後は内容を確認して再試行できる。
5. 他サロンの既存ブロックは従来どおり拒否する。

自動検証は架空データとモックDBで行う。Aily実DB、認証済み実画面、複数端末での同時削除、本番反映は未検証。
