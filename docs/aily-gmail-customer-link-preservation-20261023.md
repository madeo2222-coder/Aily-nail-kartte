# Gmail予約変更時の顧客紐付け維持（2026-10-23）

## 利用者に変わること

スタッフがHPB／minimo予約の顧客紐付けを正しい既存顧客へ修正した後に、日時・メニュー等の変更メールが届いても、修正済みの顧客紐付けを維持したまま予約変更を反映できる。

従来はメールから再判定した顧客と修正済みの顧客が異なると、安全のため同期全体を停止していた。この変更では、外部予約番号が一致する既存予約の顧客を優先し、その顧客が同じサロンに実在することを確認してから予約を更新する。

## 受入条件

1. 変更メールの再処理で、スタッフが修正した `customer_id` を維持する。
2. 顧客紐付けを維持したまま、変更後の予約日時・メニュー等を保存できる。
3. 紐付け先顧客が存在しない場合は、予約を書き込まず停止する。
4. 紐付け先顧客が別サロンの場合は、予約を書き込まず停止する。
5. 同期読取後に顧客紐付けが変更された場合の既存競合検知を維持する。

## 変更しない範囲

- 新規予約・未照合の手入力予約に対する顧客照合
- DB schema／migration／RLS／権限／環境変数
- Gmail認証・cron設定
- 実Gmail取込、実DB書込み、実顧客通知
- main／本番環境
